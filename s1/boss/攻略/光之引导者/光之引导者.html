约束满层控制

神圣脚链

吃到BOSS技能会增加约束值；达到100层后上树并眩晕5秒，受到特定强化束缚技能时会重新刷新至5秒。层数越高，受到的治疗越低。

  • 约5秒未吃技能后进入自然消减。
  • 红色：刚吃技能，不能自然净化；蓝色：受队友免疫/净化影响；白色：自然消减。
  • 首次上树没有减伤，后续上树约有60%-75%减伤，结束后层数归零。
天堂审判重复命中秒杀

天堂审判

持续受到魔法伤害并增加约束值。带有该减益时再次命中带天堂审判效果的技能，可能直接死亡。

  • 必须在减益出现后解除，提前开免疫通常无效。
  • 由净化职业及时处理；较长持续时间可交FF的T等覆盖。
绝对符文输出资源

绝对符文

P3后可抵挡绝大多数BOSS技能，同时免疫伤害、约束值和天堂审判。成功格挡指定白色技能获得绝对者力量。

  • P3上限5层，银翼阶段上限10层。
  • 每层提供6%最终伤害与5%主属性。
  • 普通束缚时-1层，强化束缚或死亡时-2层，不区分难度。
神圣权能金翼常驻

神圣权能

P4咏唱开始后获得常驻强化：额外10%减伤与10%魔抗。场地加入黄色符文，其关联技能多为纯粹伤害。

红色符文 · X

重点观察斜向攻击路径，避免站在交叉线上。

蓝色符文 · 十

重点观察横竖方向，利用斜角安全区移动。

黄色符文 · 圆环

金翼后加入，多为纯粹伤害，并可能附带短暂束缚。

参考：风法 / 包 / 痴女 / 智锤 / 女巫 / 机械或召唤 + 4C

风法 / FF

清层、群体免疫沉默、治疗和复活；重点照顾脚下队友。拉锯战中技能CD不足，需要智锤协助。

包

上增伤、拉小天使仇恨、打断治疗；次元斩与咏唱阶段保护队友并承担复活。

痴女 / CN

熟练队伍负责增伤、主断点与吃四球；智锤不熟练时帮助观察点名、带飞剑。

智锤

切换光环、解除沉默与天堂审判、治疗、带飞剑和破盾。小天使治疗增益较低时负责强抬血。

女巫 / 机械 / 召唤

女巫负责断跳、看点、治疗和破盾；机械负责断点与增伤；召唤负责聚小天使、破盾和协助解除。

4C

熟练使用绝对符文振刀，争取绝对者力量层数；保证阶段输出，同时优先躲避技能。

四剑常用分组

按楼层分配：1-2左上，3-4右上，5-7左下，8-10右下。实际人数不足时，以白圈显示的可进入人数为准。

P1

基础技能循环

一命 100%-80%

先熟悉符文颜色与BOSS朝向

01圣洁之月 · 满月斩 / 半月斩

根据外场符文颜色生成蓝色十字或红色X。满月斩会随机点名玩家并附加天堂审判；半月斩由内向外挥砍三次。

  • 红色前两刀：25%最大生命值 + 5000魔法；最后爆炸：40%最大生命值 + 5000魔法。
  • 蓝色首刀：25%最大生命值 + 5000魔法；残月与十字波：40%最大生命值 + 5000魔法。
  • 半月处理：前两刀贴近BOSS，最后移动到BOSS身后；最稳妥是持续绕背。
02天罚降临 · 点名跳

先发射大字型直线波，再随机点名玩家从空中落下，落地点消耗外场符文并生成对应颜色的X或十字。

  • 直线波：15%最大生命值 + 2500魔法；天堂审判每0.25秒造成2%最大生命值魔法伤害。
  • 落地红圈：50%最大生命值 + 17500魔法。
  • 起手贴近BOSS可避开第一段，后续远离落地点；天堂审判由净化职业立即处理。
03“给老子闭嘴” · 全屏沉默

全屏沉默、击退、减速并增加25约束值。按住S或H可以避免位移影响；在BOSS脚下按住H仍可持续普攻。免疫减益可避免沉默和减速，但仍会获得约束值。

04裁决之斩 · 后撤斩

先释放半月击退，再后撤发射两波剑气。首段为40%最大生命值 + 5000纯粹，后续剑气为25%最大生命值 + 4000纯粹，并清除护盾。

  • 近战立即绕背。
  • 远程先离开BOSS面朝中线，再向两侧移动。
05圣光裂斩 · 单 / 双

奇数次会向前挥砍、随机跳到一名玩家身后再挥砍，最后生成符文攻击；偶数次少一段点名跳跃。每次命中增加20约束值，并造成40%最大生命值 + 5000魔法伤害。

P2

真相与小天使

一命 80%-50%

四远点名、解审判、控小怪

06直面真相 · 四远扇形
  1. 接近80%时，四名无净化/治疗职责的玩家提前靠近场边，占据四个方向。
  2. 被扇形点名者不能互相覆盖，否则一起秒杀；沿外场向金色符文移动。
  3. 金色符文使玩家上树并免疫击退；净化和治疗职业负责解除带天堂审判的上树玩家。
  4. BOSS蓄力后秒杀仍带天堂审判者；之后连续全团伤害并出现高伤红圈。
07以光净汝之罪 · 双点名陷阱

随机点名两人，光圈跟随约1秒后落地并爆炸，持续造成伤害、约束、沉默和减速。圈在BOSS脚下爆炸会为BOSS恢复约1%-4%最大生命值。

处理：看到喊话全员先散开；确认不是自己后回场输出，被点名者将圈带到外侧并避免重叠。

08天空守护者 · 治疗与减疗
  • P2直面真相结束时：1-2人召唤1只、3-4人2只、5-6人3只、7人及以上4只。
  • P4天堂赞歌阶段优先复用已有小天使，并按相同人数规则补足至1/2/3/4只。
  • 小天使普攻造成6%最大生命值纯粹伤害。
  • 死亡后飞往外场，满蓝施放可打断的“天界圣光”：治疗BOSS并逐层提高减伤与受治疗量。
  • 满蓝还会施放不可打断的“你罪孽深重”，叠加持续30秒、每层17.5%的减疗，最多5层。
  • 解除控制后会冲锋最近玩家并削弱15%减伤；不要把冲锋带到BOSS脚下。
守护团结

BOSS达到50%时若仍有小天使存活，会强制获得大额减伤；小天使与BOSS重叠或小队团灭也可能触发。进入50%前必须完成小天使处理。

P3

神剑试炼

一命 50%-10%

开始获得绝对符文

50%
四圈分组斜角生成四个白圈；1-4人每圈1人、5-8人每圈2人、9-10人每圈3人。
落剑
符文格挡与击退大剑随机顺序落下；圈内获得绝对符文，落剑秒杀范围需要格挡。
约30秒
击杀四剑大剑满蓝会全屏灭团；每击杀一把会降低其余大剑回蓝速度。
09汝之意志，直面神之试炼
  • 白圈出现光柱后，圈内玩家沉默、定身并持续掉血，但锁血至20%。不要因低血量提前离圈。
  • 大剑落下时，圈外玩家被击退；面向落剑可减少击退距离，背对会被推得更远。
  • 四条移动弹幕连接外场天使与中场，接触即束缚；平地位移可穿过球间间隙。
  • 大剑可被破坏护盾提高承伤。熟练破盾者可利用击飞空档提前破盾，尽快转下一个CD。
  • 中心白球蓄力后释放扩散波；成功振刀获得绝对者力量。
10“给老子跪下” · 扩散振刀

神剑试炼结束后的下一个技能固定出现。白色扩散波可用绝对符文振刀并获得1层力量；随后场上符文停止转动，内场先爆、外场后爆。

处理：喊话时准备振刀，之后向BOSS脚下移动，避开符文爆炸路径。

11冲冲冲，光之储备

奇数次：四个光球追逐最近玩家。位移职业优先吃球；同一玩家在1.25秒减益期间继续吃球会大幅增层和受伤。

偶数次：BOSS吸收四球，连续五次点最近四人留下沉默伤害圈，随后随机点名分摊。全员散开，不贪输出；大球点名可振刀或多人分摊。

12跪伏于神怒之前 · 一阳指

“闭嘴”后的下一个技能固定出现。先抓取玩家并向面朝方向四人发射三轮剑气，随后飞到被点名者对面，向原方向释放高伤击退直线。

  • 剑气夹击无法离开时，用绝对符文抵挡前两次，第三次必须走位。
  • 主点名者提前找安全区，并让BOSS远离场边与场内光圈。
  • 最终直线躲到BOSS身后；来不及就使用绝对符文。
P4

天堂赞歌 · 金翼

一命10% → 二命100%-50%

咏唱、金轮、黄色符文

13天堂的赞歌破除罪恶 · 咏唱
  1. 进入阶段前由BB提前给盾；BOSS获得25%减伤，玩家暂时不能使用绝对符文。
  2. 随机点名四人，约3-4秒后全场沉默和减速；场边小天使发射往返金轮。
  3. 金轮回返时出现随机米字攻击，中心强制上树；结束后全员被击退到边缘。
  4. 玩家点名圈与天使圈同时爆炸或互相重叠会秒杀，点名者必须分散。
  5. BOSS身边黄色符文作为计时器：第3、6、12个亮起时释放击退波，按住H/S处理；第6-12之间还会出现相反方向米字。
圣颂减益

咏唱期间沉默且无法获得移速提升。最终核爆前绝对符文可能有约0.5秒可用窗口，可以连续尝试格挡，但不应作为常规方案。

14金翼强化技能
  • 裁决之斩·强化：后撤剑气由2/3道增加至3/4道，仍按绕背和横向离开中线处理。
  • 以光净汝之罪·强化：白圈跟随最近玩家，颜色逐渐加深后爆炸；不格挡将造成200%最大生命值伤害、50约束及沉默减速。可分摊或振刀，两个白圈不能重叠。
  • 黄色圣洁之月：满月金色点名附带天堂审判；残月追加斜米字纯粹伤害。
  • 黄色天罚降临：向场边发射五个符文，跳跃落地时收回，并在落地点外追加伤害环。
P5

万罪涤净 · 飞剑

二命 50%转换阶段

引飞盘、破盾、准备次元斩

15万罪终将涤净 · 四飞剑
  • 飞剑向四周发射弹幕，造成伤害和约束，可用绝对符文格挡；弹幕会清除护盾。
  • 专人吸引飞剑冲锋。第四次冲锋蓄力造成200%最大生命值伤害与50约束，必须格挡；队友可以代挡，成功获得1层力量。
  • 第四次冲锋后飞剑停机10秒、损失25%生命值，之后失去减伤且不再留下金色符文。
  • 每把相邻飞剑约提供33%减伤，必须拉开；破坏护盾可进一步降低减伤。
  • 非冲锋时被禁锢会导致飞剑换目标并重算吸引时间。
16唯真相永驻此间 · 五刀点名

BOSS吸收剩余飞剑并把全员拉入场内。每一把未击杀的飞剑都会让对应刀变为白色秒杀伤害。

  • 前四刀分别给一人附加对应颜色点名；前3次优先最高约束者，第4次随机。
  • 同时吃到两次点名伤害会秒杀。
  • 第5刀触发点名倒计时并造成秒杀，需要绝对符文。
  • 原攻略对最后阶段的部分走法仍标记为待补充，应以实战版本为准。
P6

最终阶段 · 银翼

二命回到60%-0%

符文恢复加快，普攻改为纯粹伤害

最终阶段优先级

打断地面天使治疗与满蓝减疗 ＞ 处理天堂审判 ＞ 次元斩点名 ＞ 输出BOSS。绝对符文上限提高到10层。

17“给老子跪下” · 强化版

扩散白波和内外符文爆炸保留；符文爆炸时，BOSS还会跳到一名玩家与自身连线的远端，再向原位置释放带范围提示的秒杀圣枪。圣枪可用绝对符文格挡并获得1层力量。

18圣光裂斩 / 一阳指 · 强化版
  • 圣光裂斩奇数次召唤2把飞剑，偶数次召唤1把；红蓝飞剑追加X或十字，黄色飞剑追踪随机玩家。
  • 强化一阳指在BOSS两侧增加2把飞剑，追击主点名玩家并秒杀路径上的单位；可以用绝对符文阻挡并获得力量。
  • 该组弹幕会清除护盾。
19圣洁之月 / 净罪 / 天罚 · 再强化
  • 残月随机追加点名；满月同时点名两人。带天堂审判时再吃另一道会秒杀。
  • 净罪保留金翼效果，并在天使脚下额外生成3-4秒后爆炸的弹幕圈。
  • 强化天罚形态不变但伤害提高：天堂审判每0.25秒造成6%最大生命值魔法伤害；站在落地红圈正中心会受到125%最大生命值魔法伤害。
20召唤天使
  • 场上只会同时存在1个地面天使，但击杀后BOSS会再次召唤。
  • 天使持续读条为BOSS回血，必须专人打断；满蓝会造成全团伤害并叠加减疗。
  • 击杀天使可消除减疗；死亡后飞往外圈回蓝。
  • 天使站在光圈内会持续回蓝；被控制后大概率冲锋最近玩家。
21有罪者，终受审 · 满蓝次元斩
  1. BOSS满蓝后获得额外50%减伤并瞬移中场。
  2. 从随机符文开始顺或逆时针点亮外侧5个符文，其中一个变白；白色不会出现在第1或第5位。
  3. 按点亮顺序连续斩5次并给玩家对应颜色点名；白色刀必须用绝对符文格挡。
  4. 前3次优先最高约束者，第4次随机；点名倒计时同时爆炸，同一玩家吃两次点名即死。
  5. 随后进入走轮。若前一个技能刚要求振刀，第二次元斩可能遇到符文仍在冷却，必须提前预留。
