灵魂收割者·斯蒂里克斯 / 判官

一、基础属性

本体：h0A1，灵魂收割者·斯蒂里克斯
变身：h0A2，灵魂融合体

h0A1：
1. 最大生命值：80000000。
2. 生命回复：50000/秒。
3. 攻击力：9105。
4. 防御：900。
5. 攻击距离：300。
6. 移动速度：250。
7. 移动类型：飞行。
8. 进入战斗后设置为Boss、初始法力0、基础减伤50%。

h0A2：
1. 最大生命值：80000000。
2. 生命回复：50000/秒。
3. 攻击力：9105。
4. 防御：900。
5. 攻击距离：750。
6. 攻击冷却：2秒。
7. 移动速度：250。
8. 移动类型：地面。


二、阶段和AI

常规循环：
1. 开战后先进入60秒周期控制器。
2. 进入主动循环后，每0.05秒推进一次内部法力/技能选择。
3. 普通形态在可行动、未暂停、未被特殊控制时随机释放技能。
4. 普通形态的基础随机池为1~7。
5. 其中部分技能需要灵魂雾/强化状态已开启才会进入释放条件。
6. 黑雷/低血技能需要强化状态，且Boss生命低于40%才会被随机到。

普通形态随机池：
1. 目标猛击：有1000范围内目标时释放。
2. 旋风斩。
3. 跳跃，要求Boss生命低于95%。
4. 灵魂之刃，要求灵魂雾/机制状态存在。
5. 愤怒，要求灵魂雾/机制状态存在。
6. 灵魂链接，要求灵魂雾/机制状态存在且强化状态开启。
7. 死亡烙印，要求灵魂雾/机制状态存在、强化状态开启且Boss生命低于40%。

强化/变身：
1. JASS中存在形态切换函数：开启时移除A14U、A0V7、A0MP、A199、A12P、A12O、A12N。
2. 开启后添加A0DA、A1AE、A0DN、A0BI、A1C9。
3. 关闭时反向恢复普通形态技能组。
4. 变身时附加40%减伤，并附加10%与20%两类额外状态。
5. 变身形态AI随机池为1~5：变身猛击、挥舞、死亡之旅、星辰闪耀、死亡之光。
6. P2页面流程口径：变身 -> 输出灯/奶灯 -> 核爆 -> 倒计时生死时速 -> 叠希望 -> 输出技能组循环。


三、普通形态技能

技能1：猛击 A14U

玩家俗称：
点名振刀 / 部分跳劈前置。

物编：
1. 冷却12秒。
2. 施法距离9999。
3. 命令基底：shockwave。

机制：
1. 以目标方向作为朝向。
2. 普通状态固定类型1。
3. 强化状态下会计数，每3次进入类型3，否则随机类型1或2。
4. 类型1/2会先做1200距离、60度扇形判定。
5. 扇形伤害：max(目标最大生命值50%, 8000)，即至少8000。
6. 扇形命中会附加灵魂相关效果。
7. 随后Boss向身后约400距离位移，并释放刀气。
8. 该技能会开启A0DK振刀分支。
9. 类型1读条1秒，类型2读条0.5秒。
10. 刀气飞行距离3000，碰撞范围400。
11. 刀气命中伤害：max(目标最大生命值75%, 12000)，即至少12000。
12. 刀气类型1命中附加灵魂效果与控制；类型2额外击退750距离。
13. 强化类型1会额外生成2条平行刀气；类型2会在位移结束后生成2条偏移刀气。
14. 强化类型3会生成目标标记、2个镜像辅助，并在后续阶段闪现到场地边缘连续放3条刀气。

振刀 / A0DK：
1. A0DK触发后读条约1.5秒。
2. IOql低于2时固定进入SILENCE分支。
3. IOql达到2后按次数交替：第一次KNEEL，第二次SILENCE，然后循环。
4. KNEEL分支会选择场内目标，Boss移动到目标身后约300距离，随后出现直线判定。
5. SILENCE分支主要是原地读条和沉默提示分支。

处理：
1. 被点名目标不要把Boss正面带向人群。
2. 正面60度和后续刀气都要躲，不能只躲第一段。
3. 强化后按“双刀/三刀”处理，不要看到Boss位移就回位。


技能2：旋风斩 A0V7

玩家俗称：
旋风劈 / 双刀。

物编：
1. 冷却15秒。
2. 命令基底：charm。

机制：
1. 每次释放会推进内部计数。
2. 普通状态第1次为1段，第2次为2段并重置计数。
3. 强化状态第1/2次为2段，第3次为3段并重置计数。
4. 每段读条1.75秒。
5. 若场内没有目标或进入第二段，会选取目标周围位置；否则以Boss当前位置为中心。
6. 类型1第一段范围650，第二段范围750。
7. 类型2第一段范围750，第二段范围850。
8. 类型3范围3000。
9. 普通段命中伤害：4000 + 目标最大生命值20%。
10. 类型3命中伤害：6000 + 目标最大生命值40%。
11. 后续四点爆发伤害统一为6000 + 目标最大生命值40%。
12. 第一轮命中会击退到750/850距离附近，并附加眩晕之击A0IY。
13. 第二轮会在四个方向生成小范围爆发，范围375或425，命中后1.5秒控制并附加灵魂效果。
14. 类型3还会出现收缩/扩张的大环和黑色爆发。

处理：
1. 看清范围圈，不要站在环带和四点爆发点。
2. 强化状态第三次旋风斩按大范围黑圈处理。
3. 被击退后不要立刻回中心。


技能3：跳跃 A0MP

玩家俗称：
点名跳劈，包含恶鬼/镜像。

物编：
1. 冷却20秒。
2. 命令基底：chemicalrage。

机制：
1. 普通状态类型1。
2. 强化状态每2次切换一次类型2，否则类型1。
3. 初段会在Boss武器上挂不同颜色指示。
4. 类型1/2都会生成移动镜像e09G。
5. 镜像持续约2秒，移动速度从2500逐渐到4000。
6. 镜像碰撞范围325。
7. 镜像命中伤害：max(目标最大生命值60%, 10000)，即至少10000。
8. 命中附加灵魂效果、0.25秒控制、A0IY眩晕之击。
9. 类型1命中击退500；类型2命中沿移动方向击退750。

处理：
1. 看到镜像/跳劈轨迹后横向离开。
2. 被点名目标带离队伍，其他人不要站在镜像路径上。


技能4：灵魂之刃 A199

玩家俗称：
月牙天冲。

物编：
1. 冷却20秒。
2. 命令基底：cloudoffog。

机制：
1. 读条1.25秒后在场地中心召唤2个h0A5魂刃单位。
2. 初始300范围爆炸。
3. 初始爆炸伤害：max(目标最大生命值30%, 5000)，即至少5000。
4. 初始爆炸附加1.5秒控制和灵魂效果。
5. 每个魂刃先做2秒环绕移动，半径从0扩到1200。
6. 环绕期间碰撞范围275。
7. 环绕命中伤害：max(目标最大生命值45%, 7500)，即至少7500。
8. 之后每个魂刃锁定目标，持续约5秒追击。
9. 追击末端650范围爆炸。
10. 追击末端伤害：max(目标最大生命值60%, 10000)，即至少10000。
11. 追击过程中每0.125秒对275范围内目标造成递增持续伤害，公式约为累计时间平方 * (4500 + 目标最大生命值25%) 的0.125倍。
12. 命中附加控制和灵魂效果。

处理：
1. 月牙不是单段，先躲中心爆，再躲环绕和追击。
2. 被魂刃锁定时要带离人群。


技能5：愤怒 A12P

玩家俗称：
灵魂愤怒 / 休想逃走 / 捕获。

物编：
1. 冷却30秒。
2. 命令基底：clusterrockets。

机制：
1. 首次释放台词：“请服从你的灵魂!”。
2. 首次释放后进入7段内部计数。
3. 释放开始时Boss加速到375。
4. 阶段中会生成大型黑暗特效和150范围恐惧/呼唤特效。
5. 每次击打会增加进度，并给Boss回血。
6. 单次回血为Boss最大生命值0.25%，并以浮字显示百分比。
7. 二次释放或后续分支会台词：“休想逃走 !”。
8. 捕获分支对场内玩家造成伤害、击退约200距离，并附加A0IY眩晕之击。
9. 捕获分支额外给Boss恢复2.5%最大生命值。
10. 多段命中会附加灵魂效果。

处理：
1. 这是回血压力技能，被抓多人会显著拖长战斗。
2. 看到“休想逃走”时分散，不要多人一起吃捕获。


技能6：灵魂链接 A12O

玩家俗称：
灯连线。

物编：
1. 冷却40秒。
2. 命令基底：coldarrows。

机制：
1. 开始台词：“感受痛苦灵魂的愤怒 !”。
2. 随机类型1或2。
3. 类型1进入青色三点旋转提示，半径525。
4. 类型2进入黑雾提示。
5. 后续会选定场内灵魂/玩家目标并建立连线。
6. 连线每0.25秒判定一次。
7. 青色阶段连线宽度150，末端200范围。
8. 灰黑阶段末端256范围。
9. 青色连线伤害为0.25 * 类型伤害；类型1基础为目标最大生命值100%，类型2为50%。
10. 也就是类型1每跳约25%最大生命值，类型2每跳约12.5%最大生命值。
11. 灰黑阶段命中也按0.25 * 类型伤害结算。
12. 命中会附加灵魂效果。
13. 灰黑阶段若判定到Boss自己被连线命中，会按命中次数回血：每次约Boss最大生命值0.1875%。

处理：
1. 重点是躲连线本体和末端圈。
2. 不要把线引回Boss身上，否则会给Boss回血。


技能7：死亡烙印 A12N

玩家俗称：
黑雷核爆 / 死亡惩罚类。

物编：
1. 冷却60秒。
2. 命令基底：coldarrowstarg。

机制：
1. 选择场内最多2名有效玩家。
2. 给目标挂ReaperMark标记和倒计时文字。

2. 爆后需要迅速治疗到满血，否则每秒继续掉10%最大生命值。

2. Boss远离目标900以上会中断。


四、P2特殊机制

希望：
1. 技能A1CC，Buff B0DA。
2. 最大20层。
3. 每层提供全伤类修正+3、属性类修正+1。
4. 自然增长为每1.5秒+1层，满20层后停止自然增长。
5. 被Boss技能命中会按技能扣希望层数，并让自然增长延后约1.5秒。
6. 死亡/变身相关机制会保留或扣除部分希望，攻略口径可理解为死亡后约保留一半。
7. 满层时显示颜色变化，图标文字为“希望(20)”。

灵魂之祖 / 灯笼：
1. 单位h0A3，名称“灵魂之祖”。
2. 灯笼初始为不可激活状态，满血后变为可激活。
3. Boss靠近灯笼600范围内会尝试引导A1C8。
4. 引导距离超过900会中断。
5. Boss身上有眩晕之击B0D3时，引导进度变为1/4。
6. 引导完成后灯笼血量压到1，并进入保护圈状态。
7. 保护圈范围325。
8. 保护人数通常为3人，10人难度/10人条件下为4人。
9. 被保护玩家获得灵魂护佑A1CE / B0D9，代码上提供100%减伤类保护。
10. 玩家离开325范围、灯笼死亡或保护源失效时，灵魂护佑会消失。

核爆 / 命运：
1. Boss满蓝后进入核爆，喊话“这就是你的命运!”。
2. 核爆读条约5秒，期间Boss法力从满值逐渐清空。
3. 读条期间会生成追踪/黑色特效干扰。
4. 核爆判定时，没有灵魂护佑的玩家会进入强制死亡/限制处理。
5. 页面口径：提前死亡的玩家墓碑会被附加灰色雾霾，无法复活。
6. 处理核心是提前打满/激活灯笼，并在核爆前进入保护圈人数内。

丰收预警：
1. Boss法力达到约75%时喊话“丰收在即 ...”。
2. 满蓝后会衔接命运核爆。
3. 场地外圈会随法力增长生成黑暗球/黑雷类预警特效。
4. 处理上看到丰收预警后，要立刻确认灯笼保护和队伍站位。

P2技能组页面俗称：
1. 吞噬希望：Boss技能命中会扣希望层数。
2. 骷髅头：P2场地骷髅/追踪物类压力。
3. 平A爆炸：Boss普攻/近身爆炸类压力。
4. 拍地板：对应变身猛击A0DA。
5. 大红：对应挥舞A1AE的内外圈大范围判定。
6. 点名锁定：对应死亡之光A1C9。
7. 旋转点名：对应死亡之旅A0DN。
8. 丰收：满蓝核爆前的预警。

处理：
1. P2第一优先级是灯笼：打满/奶满灯笼，保证核爆前有人能吃到灵魂护佑。
2. 灵魂护佑看保护数字，不要超出保护人数。
3. 输出期尽量叠希望，满希望输出收益最高。
4. 被Boss技能命中会损失希望，P2不只是躲伤害，也是保希望层数。
5. 看到“丰收在即 ...”后停止贪输出，转为确认护盾、灯笼和站位。


五、变身形态技能

技能1：变身猛击 A0DA

物编：
1. 冷却12秒。
2. 施法距离9999。
3. 命令基底：shockwave。

机制：
1. 以目标方向750距离作为落点。
2. 读条2秒后500范围爆炸。
3. 初次爆炸伤害：15000 + 目标最大生命值90%。
4. 命中附加3秒控制并击退。
5. 爆炸后从中心向5个方向生成折线路径。
6. 后续路径命中伤害：5000 + 目标最大生命值60%。
7. 路径命中附加1.5秒控制。

处理：
被点名者带离，其他人离开落点和后续5条路径。


技能2：挥舞 A1AE

物编：
1. 冷却12秒。
2. 命令基底：charm。

机制：
1. 随机内外圈模式。
2. 类型1判定0~850范围。
3. 类型2判定850~1900范围。
4. 读条2秒。
5. 命中伤害：5000 + 目标最大生命值60%。
6. 命中附加3秒控制、1秒停顿，并击退750。
7. 结束后Boss会有2.5秒硬直/恢复。

处理：
看内外圈，站到非判定区，不要固定贴Boss或固定远离。


技能3：死亡之旅 A0DN

物编：
1. 冷却20秒。
2. 命令基底：chemicalrage。

机制：

2. 随后进入4.25秒旋转追踪阶段。
3. 生成6个追踪物，半径从0扩到1750再收回0。
4. 每个追踪物命中范围85。
5. 命中伤害：max(目标最大生命值75%, 10000)。
6. 命中附加0.5秒控制和4级灵魂/限制效果。
7. 结束后Boss有2.5秒恢复。

处理：

技能5：死亡之光 A1C9

物编：
1. 冷却15秒。
2. 施法距离9999。
3. 命令基底：coldarrows。

机制：
1. 点名一个目标，并在目标位置生成锁定圈。
2. 目标玩家会收到“被锁定”提示和警告音。
3. 第一段锁定/蓄力1.5秒。
4. 第二段在Boss前方525位置生成黑球，并持续连到目标当前位置。
5. 连线每0.25秒沿线每150距离取样一次，判定150范围内、飞行高度低于175的敌对单位。
6. 目标点周围325范围也会被纳入判定。
7. 每0.25秒伤害：目标最大生命值10%。
8. 非锁定目标被连线命中会额外附加1级限制/控制效果。
9. 每0.375秒在锁定目标周围325半径的四个方向生成追踪弹。
10. 追踪弹飞行距离6000，速度750，碰撞范围100。
11. 追踪弹命中伤害：4000 + 目标最大生命值40%。
12. 追踪弹命中附加2级限制/控制效果。
13. 结束或中断后Boss有2.5秒恢复。

处理：
被点名者远离队伍并持续移动，其他人不要站在Boss与点名目标之间，也不要贴目标325范围。


六、血线机制

绝望吞噬 / 走雾黑雷跳劈：
1. h0A1初始化时注册血线阶段，阈值为60%。
2. 触发后Boss喊话“被绝望吞噬吧 !”，读条约1.5秒。
3. Boss和玩家短暂隐藏，场地四周生成黑雾，中间约550范围为安全区。
4. 黑雾每0.1秒对雾中玩家造成约5%最大生命值伤害，并附加A1CF限制效果。
5. 持续在雾中约3秒后会触发强制处决/限制处理。
6. 走雾阶段会在8个方向中随机抽取方向生成青绿色圈，方向按45度分布。
7. 每轮圈出现后，Boss按圈出现的顺序从对应方向冲刺穿过中间。
8. 玩家需要面向Boss冲刺方向承受/处理冲刺，否则会被推出安全区。
9. 命中处理包含强制位移/死亡分支，普通免控不能稳定逃课。

固定圈轮次：
1. 第1轮：4个圈，方向从8方向中随机不重复抽取。
2. 第2轮：5个圈，方向从8方向中随机不重复抽取。
3. 第3轮：4个圈，方向从8方向中随机不重复抽取。
4. 第4轮：5个圈，方向从8方向中随机不重复抽取。
5. 第1、2轮冲刺时间为0.25秒，第3、4轮冲刺时间为0.125秒，后两轮明显更快。
6. 4圈轮的出圈间隔固定约0.375秒。
7. 5圈轮按快慢混合节奏出圈，约0.5秒、0.25秒、0.5秒、0.25秒，后续沿用快速节奏。

随机圈 / 终结段：
1. 固定4轮结束后进入随机双线圈。
2. 随机段初始在横向或纵向中随机选择一种轴向。
3. 每次随机-1、0、1偏移，可能形成同向双线或左右/上下分叉双线。
4. 随机段总计2次出线，每次间隔约1秒。
5. 随后以最终偏移位置为中心生成黑雷安全点，安全点半径约500。
6. 不在安全点内会受到强制死亡/处决处理；在安全点内仍要处理后续跳劈落点。
7. Boss随后从空中砸向该点，落点半径约500。
8. 最后释放全场终结伤害，伤害约目标最大生命值150%，并喊话“你已命中注定!”。

处理：
1. 先站中间安全区，记住青绿色圈出现顺序。
2. 按圈顺序逐次面向Boss冲刺来的方向。
3. 第3、4轮冲刺更快，提前转向，不要只靠反应。
4. 随机段看双线方向，向最终安全点靠近，准备接黑雷和跳劈。
5. 被推出去后优先用高移速或位移回中间，飞天/长距离位移类逃课不作为稳定处理方案。


七、核心Debuff和关联机制

死亡惩罚 / 灵魂收获：
1. h0A1初始化时注册死亡事件监听。
2. 条件：死亡单位是玩家英雄，灵魂收割者仍存活，且死亡发生在对应Boss战区域内。
3. 普通形态下，玩家死亡会生成灵魂弹飞向Boss。
4. 灵魂弹到达Boss后只回复Boss最大生命值2%。
5. 不再触发“汲取灵魂”A1CD / B0D8。
6. 不再提高Boss的伤害类增益和减伤类增益。
7. 变身形态下玩家死亡不走灵魂弹回血分支，而是对死亡玩家附加另一段灵魂/限制处理。

破碎的灵魂（小鬼头）：
1. 技能A1CI，Buff B0DB。
2. 来源函数lo_6i，持续12秒。
3. 最大2层。
4. 每层全伤类修正-5，2层为-10。
5. 每层受伤类修正+5，2层为+10。
6. 该惩罚作用在被命中的个人身上，队友无法代替处理。

吸收灵魂 / 灵魂吸收：
1. 技能A1CB，Buff B0D6。
2. 来源函数louii，很多Boss技能命中都会附加，持续12秒。
3. 最大4层。
4. 层数按25%显示：25%、50%、75%、100%。
5. 代码显示文本为-25%、-50%、-75%、-100%，对应piuO修正从-25到-100。
6. 另有pl_O修正从+4到+10。

希望：
1. 技能A1CC，Buff B0DA。
2. 这是另一套层数，不是灵魂吸收。
3. 最大20层，每1.5秒自然增加1层。
4. Boss技能命中会扣希望层数，部分死亡/变身机制也会扣层。

眩晕之击：
1. 技能A0IY，Buff B0D3。
2. 多个技能命中后会附加。
3. 敲钟机制中，如果Boss带B0D3，引导进度变为1/4。

灵魂雾/强化状态：
1. 普通形态部分技能只有在灵魂雾/机制状态存在后才会进入AI随机池。
2. 强化状态会改变猛击、旋风斩、跳跃等技能形态。
3. 强化光环提供40%额外减伤。

回血来源：
1. 死亡惩罚：普通形态下玩家死亡，Boss回复最大生命值2%，不叠加伤害/减伤增益。
2. 愤怒技能命中阶段：每次约Boss最大生命值0.25%。
3. 愤怒捕获分支：额外恢复Boss最大生命值2.5%。
4. 灵魂链接灰黑阶段若线回到Boss：每次约Boss最大生命值0.1875%。


八、简要攻略口径

1. 先确认当前是普通形态还是变身形态，两套技能完全不同。
2. 普通形态重点躲正面扇形、刀气、旋风环、魂刃追击、连线和死亡烙印。
3. 普通形态死亡会给Boss回血并叠伤害/减伤，死人越多Boss越肉、越痛。
4. 被死亡烙印点名必须离队500范围以上，并在爆发后尽快回满血。
5. 愤怒和灵魂链接会造成Boss回血，尽量减少多人命中和连线回Boss。
6. 60%绝望吞噬要记圈序并面向冲刺方向，后两轮速度明显更快。
7. 变身形态重点躲内外圈、追踪物、点名落点和60度大扇形。
8. 敲钟可以用眩晕之击拖慢，引导距离拉开到900以上会中断。
