==================================================
一、战前速查
==================================================

基础数据
- 最大生命值：5500万
- 光之守护者（小天使）生命值：550万
- 审判之剑基础生命值：1000万
- 禁锢枷锁生命值：250万
- 初始减伤：普通96%，困难97%
- 进入战斗后减伤：普通60%，困难70%
- 困难模式物品掉率额外提高100%
- P1-P5普攻：15%最大生命值魔法伤害
- P6银翼普攻：15%最大生命值纯粹伤害
- 金翼阶段获得神圣权能：额外10%减伤、10%魔抗

主要灭团原因
1. 约束值达到100，上树后无法操作。
2. 天堂审判未解除，再吃带审判效果的技能被秒杀。
3. P2四远扇形点名互相重叠。
4. P3神剑试炼白圈缺人或大剑未及时击杀。
5. P4咏唱期间玩家点名圈与天使圈重叠。
6. P5飞剑未拉开、未破盾或未完成第四次冲锋格挡。
7. P6次元斩重复吃点名或白色刀未使用绝对符文。

开荒常用阵容
- 风法、包、痴女、智锤、女巫、机械或召唤师，加4名输出。
- 辅助之间必须提前明确：看点、解审判、治疗、破盾、小天使打断、带飞剑和复活。

四剑常用分组
- 1-2层：左上
- 3-4层：右上
- 5-7层：左下
- 8-10层：右下
- 实际人数不足时，以白圈显示的可进入人数为准。

二、核心机制
==================================================

1. 神圣脚链（约束值）
- 吃到BOSS技能会增加约束值，普通攻击通常不计算。
- 达到100后上树并眩晕5秒，期间无法操作；受到特定强化束缚技能时会重新刷新为5秒。
- 约束值越高，受到的治疗越低。
- 首次上树没有减伤；后续上树约有60%-75%减伤，结束后约束值归零。
- 约5秒没有吃到BOSS技能后，约束值开始自然下降。
- 红色：刚吃技能，不能自然净化。
- 蓝色：受到队友免疫或净化效果影响。
- 白色：处于自然消减状态。
- 可以解除负面状态，但不能仅靠提前开启免疫直接无视约束值。

2. 天堂审判
- 持续造成魔法伤害并提高约束值，不同技能持续时间和伤害不同。
- 身上已有天堂审判时，再吃带天堂审判效果的技能可能直接死亡。
- 需要在减益实际出现后解除，提前开启免疫通常不能清除。
- 智锤、风法等净化职业必须重点观察，长持续时间可交持续净化技能处理。

3. 场地符文
- 场地分为内场和外场，内外符文颜色不会完全相同。
- 红色符文对应X形攻击。
- 蓝色符文对应十字攻击。
- 外场符文会被圣洁之月、天罚降临消耗。
- 内场符文决定圣光裂斩形态，通常不会被消耗。
- 金翼后加入黄色符文，多数黄色技能为纯粹伤害或圆环伤害。

4. 绝对符文
- P3开始出现，可抵挡绝大多数BOSS技能。
- 成功抵挡时通常不会受到伤害、约束值和天堂审判。
- 格挡指定白色剑气或扩散技能可获得绝对者力量。
- P3最高5层，银翼阶段最高10层。
- 每层提供6%最终伤害和5%主属性。
- 普通束缚时减少1层，强化束缚或死亡时减少2层，不区分难度。
- 不要提前使用；看到符文提示或攻击即将命中后再按。

==================================================
三、团队职责
==================================================

风法 / FF
- 清层、群体免疫沉默、治疗、复活队友。
- 重点照顾自己脚下的队友。
- 开荒拉锯战中技能冷却通常不够，需要智锤协助。

包
- 提供增伤，拉小天使仇恨，打断小天使治疗。
- 附近有读条小天使时帮助打断。
- 次元斩、咏唱阶段保护和复活队友。

痴女 / CN
- 熟练时负责增伤、主断点和吃四球。
- 智锤不熟练时协助看点、打断和带飞剑。

智锤
- 提供增伤，切换光环，解除沉默和天堂审判。
- 负责治疗、带飞剑、破盾和吃四球。
- 小天使治疗增益较低时，使用光环或强力治疗抬血。

女巫
- 断跳、协助看点、治疗和破盾。

机械
- 负责断点和增伤。

召唤师
- 聚小天使、破盾、增伤并协助解除负面状态。

输出
- 熟练使用绝对符文振刀，争取绝对者力量层数。
- 输出优先级服从阶段机制，不要为了抢伤害吃技能。

==================================================
四、P1 一命100%-80%
==================================================

1. 圣洁之月

满月斩
- 根据外场符文颜色随机点名一名玩家。
- 红色为X，蓝色为十字，并附加天堂审判。
- 红色前两刀：25%最大生命值+5000魔法伤害。
- 红色最后爆炸：40%最大生命值+5000魔法伤害。
- 蓝色第一刀：25%最大生命值+5000魔法伤害。
- 蓝色残月爆炸与十字波：40%最大生命值+5000魔法伤害。
- 光圈爆炸约为25%最大生命值+4000魔法伤害。
- 天堂审判持续伤害约为每秒4%最大生命值魔法伤害。

半月斩
- 由内向外挥砍三次，每次命中增加约20约束值。
- 最后一段按符文颜色生成X或十字。
- 处理：前两刀贴近BOSS，最后移动到BOSS身后；最简单是持续绕背。

2. 天罚降临（点名跳）
- 起手向周围发射大字型直线波并附加短时间天堂审判。
- 随后随机点名一名玩家，从空中落下并消耗外场符文。
- 落地后按符文颜色生成红X或蓝十字。
- 直线波：15%最大生命值+2500魔法伤害。
- 天堂审判：每0.25秒2%最大生命值魔法伤害。
- 落地红圈：50%最大生命值+17500魔法伤害。
- 处理：起手贴BOSS可避开第一段；后续远离落地点，及时解除天堂审判。

3. 闭嘴吧！嘴强王者！（全屏沉默）
- 喊话：给老子闭嘴。
- 全屏沉默、击退、减速，增加25约束值并造成少量魔法伤害。
- 处理：按住S或H。BOSS脚下按住H仍可继续普攻。
- 免疫负面状态可避免沉默和减速，但仍会增加约束值。

4. 裁决之斩（后撤斩）
- 首先以BOSS为中心释放半月斩，造成击退和25约束值。
- 随后两次后撤剑气，第一波2道，第二波3道。
- 首段：40%最大生命值+5000纯粹伤害。
- 后续剑气：25%最大生命值+4000纯粹伤害，并附加眩晕和25约束值。
- 该技能弹幕会清除护盾。
- 处理：近战绕到BOSS身后；远程先离开BOSS面朝中线，再向两侧移动。

5. 圣光裂斩
- 奇数次：向前挥砍，随机跳到一名玩家身后再次挥砍，最后生成符文攻击。
- 偶数次：少一段点名跳跃挥砍。
- 每次命中增加20约束值，约造成40%最大生命值+5000魔法伤害。
- 红色看X形路径，蓝色看十字路径。

==================================================
五、P2 一命80%-50%
==================================================

1. 直面真相
- 80%时场边12、3、6、9点出现光圈，场中随机出现金色符文。
- 接触金色符文会被上树，但可以免疫击退。
- 点名四名最远玩家形成扇形，扇形会击退路径上的非上树玩家。
- 四个扇形不能互相覆盖，否则被覆盖玩家一起死亡。
- BOSS随后击退全场，扇形方向会被大幅推出平台。
- 扇形附加持续时间较长的天堂审判。
- 最后BOSS蓄力秒杀仍带天堂审判的玩家，并继续造成多波全团伤害。

处理流程
1. 接近80%时，提前安排四名没有净化、治疗职责的玩家站到场边四个方向。
2. 四人分别占据不同区域，避免扇形重叠。
3. 被点名者由外场向金色符文移动，利用上树免疫击退。
4. 净化与治疗职业负责解除上树玩家的天堂审判并维持血量。
5. 其余玩家避开随机红圈和后续全团伤害。

2. 以光净汝之罪（双点名陷阱）
- 随机点名两名玩家生成光圈。
- 光圈跟随约1秒后落地爆炸，释放沉默球。
- 圈内持续受到伤害、约束值、沉默和减速。
- 每个球约增加15约束值。
- 圈在BOSS脚下爆炸会为BOSS恢复约1%-4%最大生命值。
- 处理：看到喊话全员先散开；确认不是自己后回场输出，被点名者将圈带到外侧。

3. 天空守护者（小天使）
- P2直面真相结束时：1-2人召唤1只、3-4人2只、5-6人3只、7人及以上4只。
- P4天堂赞歌阶段优先复用已有小天使，并按相同人数规则补足至1/2/3/4只。
- 普攻造成6%最大生命值纯粹伤害。
- 死亡后飞到外场，获得高额减伤并开始回蓝。
- 小天使与BOSS或其他小天使靠得太近会获得守护团结。

天界圣光
- 满蓝后施放，可被控制技能打断。
- 治疗BOSS约2%最大生命值，并逐层提高BOSS减伤和受到的治疗量。
- 多次成功施放后，减伤最高约20%，受治疗量最高约100%。

你罪孽深重
- 满蓝后对全队落下审判并清空蓝条，无法打断。
- 每层附加17.5%减疗并持续造成伤害，持续30秒，最多5层。
- 必须在满蓝前击杀或控制，否则治疗压力会迅速失控。

天惩（点名冲锋）
- 解除控制后，点名最近玩家冲锋。
- 命中后削弱玩家15%减伤并造成中等伤害。
- 被点名者不要把小天使带到BOSS脚下，召唤物可协助承受。

守护团结
- BOSS达到50%时若小天使仍存活，会强制获得大额减伤。
- 小天使与BOSS重叠或小队团灭也可能触发。
- 进入50%前必须完成小天使处理。

==================================================
六、P3 一命50%-10%
==================================================

1. 汝之意志，直面神之试炼（四剑走轮）
- 50%后四个斜角生成白圈。
- 1-4人时每圈需要1人；5-8人时每圈2人；9-10人时每圈3人。
- 白圈出现光柱后，圈内玩家被沉默和定身，持续掉血但锁血至20%。
- 四把大剑随机顺序落下，圈外玩家受到击退，圈内玩家获得绝对符文。
- 大剑落点为秒杀范围，需要使用绝对符文格挡。
- 面向落剑可减少击退距离，背对落剑会被推得更远。
- 场外天使与中场形成四条移动弹幕，接触会被束缚。
- 平地位移可利用球与球之间的间隙穿过。
- 大剑满蓝后会释放全屏灭团技能，第一把约30秒，击杀后其余大剑回蓝变慢。
- 每把大剑都可以破坏护盾，提高其受到的伤害。

处理流程
1. 按楼层或队伍编号提前分配四个白圈。
2. 进入白圈后不要因为低血量提前离开。
3. 大剑落下时观察方向并使用绝对符文振刀。
4. 自己组大剑落下后立即转中场，观察下一把剑顺序。
5. 破盾职业尽快破盾，所有人按顺序集火大剑。
6. 避开大剑脚下以外的扩散弹幕和中心白球扩散波。

注意
- 有皮肤的MY职业不要在中心白球即将消失时使用Q，可能影响队伍判断。

2. 给老子跪下！（扩散振刀）
- 神剑试炼结束后的下一个技能固定出现。
- 白色扩散光波可以用绝对符文格挡，成功获得1层绝对者力量。
- 随后场上符文停止转动，内场先爆炸，外场后爆炸。
- 处理：喊话时准备振刀，完成后向BOSS脚下移动，避开符文爆炸。

3. 冲冲冲，光之储备

奇数次
- 四个光球追逐最近玩家。
- 碰撞造成全团伤害并给吃球者附加1.25秒金球减益和5约束值。
- 减益期间继续吃球会额外增加约30%层数并受到更高伤害。
- 处理：位移职业优先吃球；层数高时换人。技能出现后全员向BOSS附近靠拢。

偶数次
- BOSS吸收四球，连续5次点名最近4人并留下沉默、减速、伤害和约束圈。
- 随后随机点名一人分摊，无人分摊会死亡，召唤物不能分摊。
- 处理：全员先散开，不要贪输出；大球可用符文格挡或多人分摊。

4. 跪伏于神怒之前（一阳指）
- BOSS施放一次“闭嘴”后，下一个技能固定为一阳指。
- 先向BOSS身边抓取玩家。
- 对面朝方向的4名玩家连续释放3次剑气。
- 同时随机点名未被剑气选中的玩家，在其脚下生成标记。
- 剑气命中增加约束并造成束缚，束缚期间不能使用绝对符文。
- 随后BOSS飞到主点名玩家对面，向原方向释放高伤击退直线。
- 上树状态被最终直线命中会直接死亡。
- 该技能弹幕会清除护盾。

处理
- 剑气点名被夹住时，可用绝对符文挡前两次，第三次必须走位。
- 主点名玩家提前找安全区，并让BOSS远离场边和场内光圈。
- 剑气结束后躲到BOSS身后；无法到达时使用绝对符文。

==================================================
七、P4 金翼阶段
一命10% -> 二命100%-50%
==================================================

1. 天堂的赞歌破除罪恶（咏唱）
- BOSS降至10%后进入咏唱并获得25%减伤，期间不能使用绝对符文。
- 随机点名4人，约3-4秒后全场沉默并降低移速。
- 小天使固定到场地边缘释放往返金轮；1-2人补足1只、3-4人2只、5-6人3只、7人及以上4只。
- 金轮回返时，BOSS释放随机方向米字攻击，中心点强制上树。
- 米字结束后全员被击退到边缘。
- 玩家点名圈与天使圈互相重叠并同时爆炸会秒杀。
- BOSS身边黄色符文作为计时器，第3、6、12个亮起时释放击退波。
- 第6至第12个符文之间还会出现一次相反方向米字攻击。

处理流程
1. 进阶段前由包或对应职业提前给盾。
2. 四名点名玩家分散，不要与天使圈或其他玩家圈重叠。
3. 熟悉金轮往返路径，米字出现时避开中心。
4. 第3、6、12个黄色符文亮起前按住H或S。
5. 最终核爆前符文可能短暂恢复约0.5秒，可以连续尝试格挡，但不能依赖该异常机制。

咏唱减益：圣颂
- 沉默。
- 无法获得移动速度提升。
- 某些职业技能可能不受减速影响，属于版本差异或异常行为。

2. 裁决之斩·强化
- 后撤剑气由2道、3道提高为3道、4道。
- 处理仍为近战绕背，远程先离开中线再向两侧移动。

3. 以光净汝之罪·强化
- 随机点名两名玩家生成白圈。
- 白圈附着2-3秒后缓慢追踪最近玩家，颜色逐渐加深后爆炸。
- 不使用绝对符文时，造成200%最大生命值伤害、50约束、沉默和减速。
- 白圈可以分摊或振刀，振刀成功获得1层绝对者力量。
- 没有绝对符文的玩家可站进白圈获得符文，但必须正确处理爆炸。
- 两个白圈不能重叠，也不能带到BOSS脚下。
- 第一个圈大概率索敌约束值最高玩家，第二个随机。

4. 黄色符文技能
- 黄色圣光裂斩：奇数次多一次跳跃；攻击多为纯粹伤害。
- 黄色满月：金色点名并附加天堂审判。
- 黄色半月：残月追加斜米字范围攻击。
- 黄色天罚：向场边发射5个符文，跳跃落地时收回，并在落地点外追加伤害环。
- 黄色“跪下”：金色符文爆炸为圆环伤害，并束缚约0.5秒。

==================================================
八、P5 二命50%飞剑转换
==================================================

1. 万罪终将涤净，尔之存在终归尘烬
- BOSS召唤4把飞剑并向四周发射弹幕，弹幕造成伤害和约束，可用符文格挡。
- 1-2人同时激活2把，3-4人同时激活3把，5人及以上同时激活4把；待机飞剑无敌且暂停，完成一把第四次冲锋后依次激活下一把。
- 弹幕会清除护盾。
- 飞剑随后移动到场边四个圆心，需要专人吸引冲锋。
- 第4次冲锋会蓄力，造成200%最大生命值伤害并增加50约束。

- 完成第4次冲锋后，飞剑停机10秒并损失25%生命值，随后失去全部减伤。

- 每把飞剑可使用破坏护盾降低减伤。
- 飞剑飞行会留下金色符文，踩到会持续增加约束值。
- 非冲锋过程中被禁锢，飞剑会更换目标并重新计算吸引时间。

2. 唯真相永驻此间

- 第5刀触发点名倒计时并造成秒杀，需要绝对符文。

- 某些情况下技能结束会清空约束值，触发条件尚未完全确认。
